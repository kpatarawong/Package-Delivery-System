# Package Delivery System
Description
This package delivery system is built using Python and utilizes CSV data for delivery addresses and their distances to one another, as well as package constraints. This project is the main project for C950 of WGU's computer science program.

# Features
Uses CSV data for delivery addresses and distances
Takes package constraints into account when creating delivery routes
Generates optimized delivery routes for efficient package delivery

# Usage
Run the command python main.py in the root directory of the repository to start the program
Follow the prompts to view packages at desired times.

# Requirements
Python 3.x 

# Installation
Ensure that all requirements are met
Clone the repository using the command: git clone https://github.com/yourusername/Package-Delivery-System.git
Navigate to the root directory of the cloned repository
